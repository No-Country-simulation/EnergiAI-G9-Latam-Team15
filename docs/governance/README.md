# docs/governance/

Gobernanza técnica del proyecto: auditorías generales, matrices de dependencias, estado de entregables y síntesis ejecutivas.

## Contenido

- `AUDITORIA_PROYECTO_v1.md` — auditoría técnica integral del repositorio (arquitectura, backend, ML, frontend, infraestructura, CI/CD).
- `MATRIZ_DEPENDENCIAS_SPRINT2.md` — dependencias entre las tareas del Backlog Sprint 2, camino crítico hacia el despliegue OCI y contraste entre lo reportado en actas y el estado real del repositorio.
- `ENTREGABLES_NOCOUNTRY.md` — estado de los entregables identificados por el equipo para la evaluación de NoCountry.
- `RESUMEN_EJECUTIVO_AUDITORIA_SPRINT2.md` — síntesis de una página para lectura ejecutiva (Product Owner / jurado / stakeholders).

## Relación con `planning/`

`planning/` (raíz) contiene la planificación prospectiva del equipo (roles, riesgos iniciales, roadmap, backlog). `docs/governance/` contiene la auditoría retrospectiva de cómo va ese plan frente a la realidad del código — ambas carpetas se citan mutuamente y deben leerse en conjunto, nunca de forma aislada.
