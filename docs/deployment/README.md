# docs/deployment/

Planificación, checklist y veredicto de disposición para el despliegue de EnergiAI en Oracle Cloud Infrastructure (OCI).

## Contenido

- `PLAN_DESPLIEGUE_OCI_v1.md` — arquitectura de despliegue objetivo, servicios OCI requeridos y secuencia operativa para el primer despliegue técnico (Tarea #10 del Backlog Sprint 2).
- `CHECKLIST_OCI.md` — checklist de ejecución paso a paso para el despliegue, con casillas de verificación por fase.
- `OCI_READINESS_REPORT.md` — veredicto formal: ¿puede EnergiAI desplegarse en OCI hoy? Qué falta, quién es responsable y qué tarea del backlog lo respalda.

## Cuándo actualizar

Estos documentos deben revisarse cada vez que se cierre una tarea crítica del camino hacia el despliegue (ver `docs/governance/MATRIZ_DEPENDENCIAS_SPRINT2.md`), y en particular antes de cada intento real de despliegue en OCI, para evitar ejecutar pasos sobre supuestos desactualizados.
